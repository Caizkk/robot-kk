# 和元智擎智能机器人

基于 Electron + Vue3 + Element Plus 构建的现代化桌面应用，用于设计和配置智能机器人。

## 技术栈

- Electron v22.3.26
- Vue v3.2.47
- Element Plus v2.3.8
- TypeScript
- Vite

## 功能特点

- 现代化的用户界面
- 跨平台支持 (Windows, macOS, Linux)
- 机器人设计面板
- 配置管理
- 数据分析

## 开发环境设置

### 前提条件

- Node.js 16+
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 开发模式运行

```bash
npm run dev
```

### 构建应用

```bash
npm run build
```

## 项目结构

- `electron/`: Electron 主进程代码
- `src/`: Vue 应用代码
  - `components/`: Vue 组件
  - `assets/`: 静态资源
- `public/`: 公共静态资源
